# 📌 Final Presentation - [Monitoring of Export and Import Results with a Focus on Comparative Analysis between Brazilian States and Municipalities within the State of São Paulo]

## 🎯 Objectives of the MVP

To develop a **Business Intelligence platform** that enables the monitoring of Brazil’s export and import performance, with a specific focus on the municipalities within the State of São Paulo.

* **What problem does it solve?**
  **A:** The lack of an accessible and simplified means of locating and analyzing such data for research and management purposes.
* **What hypothesis will be validated?**
  **A:** That a BI platform leveraging **Power BI** can provide a simplified interface connected to the **ComexStat database**, which will be cleaned and structured using the **Python programming language** together with the **Pandas library**.
* **What value will be delivered to the end user?**
  **A:** With this tool, users will be able to easily access highly relevant data that can be used by companies and managers as a reference for future strategic planning.

---

## 📝 Description

This MVP consists of a **Business Intelligence platform** designed to facilitate access to data related to Brazilian foreign trade. It integrates with the **ComexStat database**, which is cleaned and prepared using **Python**, and visualized through an interactive **Power BI Dashboard**.
The dashboard includes filters related to **transport modes**, **municipalities in São Paulo**, and **Brazilian states**.

**Key Points:**

* ComexStat Database processed using **Python** and the **Pandas** library;
* Dashboard interface displaying information related to Brazilian foreign trade (Exports and Imports) from **2023 to 2025**;
* Implementation of filters by **municipalities (São Paulo)**, **states (Brazil)**, **transport modes**, and other variables for comparative analysis.

---

## 👥 Personas / Target Users

* **Persona 1:** *Public Foreign Trade Manager* — needs to monitor the performance of municipalities in São Paulo; faces challenges accessing comparative regional data and identifying market trends.
* **Persona 2:** *Export Analyst / Private Company* — seeks to understand risks, tariffs, and international opportunities; lacks clarity on tariff impacts and struggles to plan efficient logistics routes.
